# Cisco Packet Tracer Labs

A collection of 12 networking labs completed using Cisco Packet Tracer. This repository documents practical networking concepts, device configurations, connectivity testing, troubleshooting procedures, verification commands, and lab results.

## Objectives

- Practise fundamental computer networking concepts.
- Understand network device configuration and communication.
- Learn IPv4 and IPv6 addressing and connectivity.
- Explore network protocols such as DHCP, DNS, ARP, FTP, Telnet, and SSH.
- Troubleshoot network connectivity using command-line tools.
- Document practical exercises with topology diagrams and screenshots.
- Build a networking portfolio for academic and professional development.

## Tools and Commands Used

- **Cisco Packet Tracer** — network simulation and device configuration.
- **Command Prompt** — connectivity testing and network diagnostics.
- **Router CLI** — router configuration and verification.
- `ping` — tests connectivity between devices.
- `ipconfig /all` — displays IPv4 configuration information.
- `ipv6config /all` — displays IPv6 configuration information.
- `tracert` — traces the route to a destination.
- `arp -a` — displays the ARP cache.
- **DHCP** — automatically assigns IP configuration to clients.
- **Telnet and SSH** — remote device access.
- **FTP** — transfers files between clients and servers.
- **Web browser** — tests web access and observes web requests.
