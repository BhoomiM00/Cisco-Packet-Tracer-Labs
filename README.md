
# Cisco Packet Tracer Labs

A collection of networking labs completed using Cisco Packet Tracer. This repository documents practical networking concepts, device configurations, troubleshooting procedures, verification commands, and lab results.

## Objectives

- Practise fundamental computer networking concepts.
- Understand network device configuration and communication.
- Learn network troubleshooting using command-line tools.
- Document practical exercises with topology diagrams and screenshots.
- Build a networking portfolio for academic and professional development.

## Labs

| No. | Lab Name | Topics Covered |
|---|---|---|
| 01 | [Use the `ping` Command](01-Use-the-Ping-Command/README.md) | Connectivity testing, DNS troubleshooting, IP configuration |

## Tools Used

- Cisco Packet Tracer
- Command Prompt
- `ping`
- `ipconfig /all`
- Web Browser
